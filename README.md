# Shivansh Agarwal Portfolio

A responsive, single-page editorial portfolio inspired by the visual language of whyramachandran.design and rebuilt with Shivansh Agarwal's own content, résumé, photograph, projects and experience.

## Run locally

Open `index.html` directly, or serve the folder with any static server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

The folder is ready for GitHub Pages, Netlify, Vercel static hosting, Cloudflare Pages, or any standard web server. No build step is required.

## Main files

- `index.html` — complete one-page portfolio
- `styles.css` — responsive layout and animations
- `script.js` — reveal effects, mobile navigation, cursor and case-study dialogs
- `assets/Shivansh_Agarwal_Resume.pdf` — downloadable résumé
- `assets/shivansh-profile.jpg` — profile image
