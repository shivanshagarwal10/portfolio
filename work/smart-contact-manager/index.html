OVERVIEW

A secure, full-featured contact manager.

Smart Contact Manager lets a user register, verify their email, and securely store and organize their contacts — with profile images in the cloud, email sending built in, search and pagination, exports and a light/dark UI. I built it end to end with Spring Boot on the backend and a Thymeleaf + Tailwind interface.

It was my internship project at Euonus IT during my B.Tech program, and it covers the full lifecycle of a real product: authentication, data, file uploads, third-party integrations and secured routes.

FEATURES

What it does.

AUTH

Sign-in & verification

Email/password registration plus OAuth2 login with Google and GitHub, and email verification required before first login.

CONTACTS

Full contact CRUD

Create, view, update and delete contacts, mark favorites, and browse with search and pagination.

MEDIA

Cloud image upload

Profile and contact images uploaded to the cloud via Cloudinary / AWS S3 rather than stored on the server.

EMAIL

Email integration

Send emails with attachments directly from the app using the JavaMail API.

DATA

Export & organize

Export contact data to Excel/CSV, plus user profile management and a light/dark mode toggle.

SECURITY

Protected routes

Route protection and access control with Spring Security, verified through manual testing.

ENGINEERING HIGHLIGHTS

How it's built.

  • Spring Boot backend using Spring MVC, Spring Security and Spring Data JPA.
  • OAuth2 login (Google & GitHub) alongside email/password with pre-login email verification.
  • Cloud file uploads for images through Cloudinary / AWS S3.
  • Transactional email with attachments via the JavaMail API.
  • Server-rendered UI with Thymeleaf, Tailwind CSS and Flowbite, plus JavaScript for dynamic features.
  • Search, pagination, favorites, CSV/Excel export and secured routes — tested manually.
